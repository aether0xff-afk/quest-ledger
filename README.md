# Quest Ledger

A personal quest and todo-list mod for **Minecraft Java Edition 26.2 + Fabric**.

Quest Ledger turns ordinary tasks into lightweight in-game quests. Players can create completion rules in either of two interchangeable ways:

- **Builder mode** — buttons, selectors, number fields, and manual completion rules.
- **QuestScript mode** — a small safe language that can be written manually or generated by asking an external LLM such as ChatGPT.

The mod itself does **not** connect to or run an LLM. QuestScript can be copied into any chatbot together with the included language documentation, then pasted back into the mod.

- an in-game quest-type guide with practical examples;
- persistent manual confirmations scoped to each world or server;
- automatic runtime evaluation every five client ticks;
- immediate completion when a condition becomes true, with no configurable timer;
- creation-relative mining, crafting, use, pickup, drop, and kill statistics;

- an animated HUD showing up to three active quests;
- Korean and English localization;
- backend-neutral GUI rendering for both Vulkan and OpenGL;
- parser self-tests and a GitHub Actions build.

## Quest completion modes

### Automatic

Minecraft can measure the goal directly.

```questscript
quest "위더 처치" {
  complete when {
    stat.killed("minecraft:wither") >= 1
  }
}
```

Other automatic goals include mining blocks after quest creation, holding a certain item amount, crafting or using items, reaching coordinates, entering a dimension, and combining supported conditions.

### Manual

Use manual completion when the game cannot reliably determine whether a project is finished or good enough.

```questscript
quest "금 공장 완성" {
  complete when {
    manual.checked == true
  }
}
```

Open **Active Quests** and press **Confirm Complete**.

### Hybrid

Manual confirmation can be combined with measurable evidence.

```questscript
quest "금 공장 가동 확인" {
  complete when {
    manual.checked == true
    and inventory.count("minecraft:gold_ingot") >= 64
  }
}
```

See [`docs/QUEST_TYPES.md`](docs/QUEST_TYPES.md) for more examples and guidance.

## No configurable completion timer

Quest Ledger checks conditions every five client ticks. When an expression becomes true, completion begins immediately. The mod plays one short fixed visual effect before removing the quest; this effect duration is internal and is not a QuestScript option.

Older `hold` and `remove after` fields are accepted only while reading legacy quest files. The editor and GPT-facing formatter do not output them, and the runtime ignores them.

## Storage

Each world or server receives its own directory:

```text
config/quest-ledger/worlds/<scope-name>-<hash>/
  scope.properties
  quests.qs
  runtime-state.properties
  manual-state.properties
  completed-history.log
```

Singleplayer scopes use the normalized save path. Multiplayer scopes use the server address. Switching worlds or servers unloads the previous scope before loading the next one.

When upgrading from 0.1, the old client-wide quest and history files are moved into the first opened scope and archived under `config/quest-ledger/legacy/`.

## Statistic semantics

QuestScript statistic functions count progress made **after that quest was created**:

```questscript
quest "고대 잔해 네 개 더" {
  complete when {
    stat.mined("minecraft:ancient_debris") >= 4
  }

  animation "wax_seal"
}
```

If the vanilla statistic was already 100 when the quest was saved, Quest Ledger stores 100 as the baseline and completes at 104. The baseline is kept in `runtime-state.properties` and survives game restarts.

Inventory conditions remain absolute. For example, `inventory.count("minecraft:diamond") >= 4` checks the player's current inventory rather than items acquired after creation.

## Toolchain

- Minecraft: `26.2`
- Fabric Loader: `0.19.3`
- Fabric API: `0.156.0+26.2`
- Fabric Loom: `1.17-SNAPSHOT`
- Gradle: `9.5.1`
- Java: `25`

Minecraft 26.2 can use either Vulkan or OpenGL. Quest Ledger therefore renders through Minecraft/Blaze3D abstractions and Fabric HUD APIs instead of calling either graphics backend directly. See [`docs/RENDERING_BACKENDS.md`](docs/RENDERING_BACKENDS.md).

## Build

Install JDK 25, then run:

```shell
./gradlew build
```

On Windows:

```powershell
.\gradlew.bat build
```

The remapped mod JAR is produced in `build/libs/`.

See [`docs/QUESTSCRIPT.md`](docs/QUESTSCRIPT.md), [`docs/ASK_GPT.md`](docs/ASK_GPT.md), [`docs/QUEST_TYPES.md`](docs/QUEST_TYPES.md), [`docs/EDITOR_MODES.md`](docs/EDITOR_MODES.md), and [`docs/RUNTIME_SUPPORT.md`](docs/RUNTIME_SUPPORT.md).
