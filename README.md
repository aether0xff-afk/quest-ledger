# Quest Ledger

A personal quest and todo-list mod for **Minecraft Java Edition 26.2 + Fabric**.

Quest Ledger turns ordinary tasks into lightweight in-game quests. Players can create completion rules in either of two interchangeable ways:

- **Builder mode** — buttons, selectors, number fields, and sliders.
- **QuestScript mode** — a small safe language that can be written manually or generated by asking an external LLM such as ChatGPT.

The mod itself does **not** connect to or run an LLM. QuestScript can be copied into any chatbot together with the included language documentation, then pasted back into the mod.

## Current milestone

This repository currently contains the 26.2 Fabric project foundation and the first QuestScript language core:

- lexer and parser;
- typed AST shared by both editor modes;
- semantic validation with a whitelist of properties and functions;
- canonical source formatter;
- self-test executed by Gradle `check`;
- Korean and English localization foundations;
- design and language documentation.

The in-game medieval UI, HUD, persistence, and event-driven condition evaluator are the next implementation milestone.

## Toolchain

- Minecraft: `26.2`
- Fabric Loader: `0.19.3`
- Fabric API: `0.156.0+26.2`
- Fabric Loom: `1.17-SNAPSHOT`
- Gradle: `9.5.1`
- Java: `25`

Minecraft 26.2 uses an optional Vulkan backend, so rendering code must use Minecraft/Blaze3D abstractions rather than raw OpenGL.

## Build

Install JDK 25 and Gradle 9.5.1, then run:

```shell
gradle build
```

The mod JAR is produced in `build/libs/`.

The Gradle wrapper will be added after the initial repository bootstrap; until then use a local Gradle installation matching the version above.

## Small example

```questscript
quest "네더라이트 하나 더" {
  id "one_more_netherite"
  description "네더라이트 주괴를 하나 확보한다."

  complete when {
    inventory.count("minecraft:netherite_ingot") >= 1
    or stat.mined("minecraft:ancient_debris") >= 4
  }

  hold 1s
  remove after 1200ms
  animation "wax_seal"
}
```
